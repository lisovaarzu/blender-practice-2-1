ВОССТАНОВЛЕНИЕ КОМПЛЕКТА В WINDOWS

1. Скачайте все четыре части в одну папку. Сохраните исходные имена:
   Practice_2_1_Complete.zip.001
   Practice_2_1_Complete.zip.002
   Practice_2_1_Complete.zip.003
   Practice_2_1_Complete.zip.004

Это двоичные части одного ZIP. По отдельности их открывать не нужно.

2. В Проводнике откройте эту папку, в адресной строке введите cmd и нажмите Enter.

3. Скопируйте следующую команду целиком и нажмите Enter:

copy /b Practice_2_1_Complete.zip.001+Practice_2_1_Complete.zip.002+Practice_2_1_Complete.zip.003+Practice_2_1_Complete.zip.004 Practice_2_1_Complete.zip

Команда выполняется в cmd, а не в PowerShell. При запросе замены уже существующего ZIP сначала убедитесь, что старый файл вам не нужен, или используйте отдельную пустую папку.

4. Необязательная, но рекомендуемая проверка в том же окне cmd:

certutil -hashfile Practice_2_1_Complete.zip SHA256

Ожидаемый SHA256:
58c9b8d9318da9ba9165c2ffb0c0575225565194029e662b4bbf0f7067a09adf

Размер восстановленного ZIP: 259896573 байт.

5. Откройте восстановленный Practice_2_1_Complete.zip и выберите «Извлечь всё».
Откройте Practice_2_1\Blender\Practice_2_1_Final.blend в Blender 5.3.0.
Сохраните структуру папок. Внешние текстуры также упакованы внутрь .blend.
Для открытия проекта не нужны сторонние аддоны.

Нужно около 1 ГиБ свободного места для частей, восстановленного ZIP и распакованного проекта.

ОГРАНИЧЕНИЕ ПЕРЕДАЧИ
Эти файлы реально существуют в рабочей среде Codex. Доступная интеграция не предоставляет отдельного инструмента публикации скачиваемых вложений. Ссылки на пути поддерживают «Сохранить как…» только в совместимом клиенте. Успешное скачивание именно в вашем браузере не проверено.
Если ошибка повторится и для 70-МиБ части, требуется другой канал передачи: например GitHub Release Assets после восстановления авторизованного доступа. Переименование внутреннего пути в ссылку sandbox:// не создаёт вложение.
